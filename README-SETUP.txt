SUBHOJEET GHOSH — VICE CITY PROFILE STARTER

1. Extract this ZIP to C:\Subhojeet1403
2. Open PowerShell in that folder.
3. If this is your existing GitHub profile repository, connect it with:
   git init
   git branch -M main
   git remote add origin https://github.com/Subhojeet1403/Subhojeet1403.git
   git pull origin main --allow-unrelated-histories
   (If the folder is already a Git repository, do not run git init or add the remote again.)
4. Add your banner at assets/banners/gtavi-banner.jpg.
5. Add project screenshots to assets/projects/.
6. Review README.md and update any details that have changed.
7. Commit and push:
   git add .
   git commit -m "Build Vice City cybersecurity profile"
   git push -u origin main

SNAKE WORKFLOW
The workflow is .github/workflows/snake.yml.
After pushing it, open GitHub > repository > Actions > Generate Contribution Snake > Run workflow.
The workflow publishes generated SVG files to the output branch.
The profile README references the dark SVG in that output branch.
